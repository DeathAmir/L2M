Lua API Reference

Learn what each Lua function does, which arguments it accepts, when it runs, and what it changes in Minecraft. The reference below follows the implementation in this repository.

Experimental
i
API stability

These methods describe the implementation currently in the repository. Signatures and behavior may change between releases.

Chat messages

Print a message in your local chat window with the [L2M] prefix. This is a client-side display only: it does not broadcast to a server or to other players. All three names call the same local-message implementation.

l2m.chat(message)Client
l2m.clientChat(message)Alias
l2m.systemChat(message)Alias
Lua
l2m.chat("Hello from Lua!")
l2m.clientChat("Local message")
l2m.systemChat("System-style local message")
ParameterTypeDescription
messagestringMessage text. Current bridge accepts 1–256 characters and rejects blank input.

Logging

Write a message to the L2M logger with a Lua prefix.

l2m.log(value)Client
Lua
l2m.log("Script started")
l2m.log("Player level: " .. tostring(level))
ParameterTypeDescription
valueanyAny Lua value. L2M converts it to text and writes it to the Minecraft log with the [Lua] prefix.

HUD drawing

Add drawing instructions to the HUD render queue. Coordinates are pixels from the top-left of the game GUI. These functions do not create a Minecraft item or world object; they draw over the interface.

l2m.drawText(x, y, text, color?)Client
l2m.drawRect(x, y, width, height, color)Client
l2m.clearDraw()Client
Lua
l2m.drawText(12, 12, "L2M is active")
l2m.drawText(12, 30, "Custom color", 0xFF50E0D2)
l2m.drawRect(10, 52, 140, 3, 0xFF50E0D2)
l2m.clearDraw()
ParameterTypeDescription
x, yintegerTop-left screen coordinates.
textstringText to draw; maximum 512 characters.
width, heightintegerRectangle dimensions, each in the 0–4096 range.
colorintegerARGB color. drawText defaults to opaque white.

Drawing instructions remain visible on subsequent HUD frames. Calling clearDraw() removes all queued instructions. Starting another script also clears the previous queue before execution.

Generated content definitions

These methods write JSON definitions under config/l2m/generated/blocks or items. Minecraft registries are initialized before ordinary client scripts run, so a definition created by a manually executed script is not registered immediately: restart Minecraft after creating it. Packages have a special early registration pass for their entrypoint.

l2m.registerBlock(id, properties)Startup
Lua · Block definition
l2m.registerBlock("ruby_ore", {
  displayName = "Ruby Ore",
  hardness = 3.0,
  requiresTool = true
})
l2m.registerItem(id, properties)Startup
Lua · Item definition
l2m.registerItem("ruby", {
  displayName = "Ruby",
  stackSize = 16
})
PropertyApplies toBehavior
idBoth1–48 lowercase letters, numbers or underscores.
hardnessBlockOptional number; defaults to 1.5.
requiresToolBlockOptional boolean; defaults to false.
stackSizeItemOptional integer from 1–99; defaults to 64.

The current registry loader uses the block ID, hardness and requiresTool values, or the item ID and stackSize. The saved displayName field is not currently applied to Minecraft's visible item name. Custom models, textures, recipes and live registry changes are not implemented by these methods.

Client commands

These are client commands. They execute Lua inside your Minecraft client, not on a dedicated server.

/l2m run <file>

Execute config/l2m/scripts/<file>.lua. Omit the extension.

/l2m package run <package> <script>

Execute a Lua file inside an installed package's scripts directory.

/l2m packages

List package directories under config/l2m/packages.

Package format

Use /l2m packages to list package folders. Use /l2m package run <package> <script> to run a named Lua file from that package's scripts folder.

A package is a directory inside config/l2m/packages. It must contain package.json with an ID matching the folder and a Lua entrypoint. The entrypoint is first evaluated during mod startup to collect registerBlock/registerItem definitions; it is then automatically executed when the client joins a world.

package.json
{
  "id": "my_package",
  "entrypoint": "scripts/main.lua"
}

The manifest ID must match the package folder. The entrypoint is a relative Lua path inside that package and must end in .lua. Do not use a path that escapes the package directory.
