Lua API
v0.1

The initial L2M client API is intentionally small.

l2m.chat(message)

Sends a chat message using the local Minecraft client connection.

  • message — string, not empty, maximum 256 characters.
  • Returns — no Lua value.
  • Requires — the player must be in a world with an active connection.
l2m.chat("Hello from Lua!")

Runtime

L2M bundles LuaJ 3.0.1 inside the mod JAR using NeoForge Jar-in-Jar. LuaJ provides a Lua 5.1-compatible scripting environment; this is not the native Lua C library.

Scripts run locally on the client. Treat scripts as trusted code and do not install scripts from unknown sources.
