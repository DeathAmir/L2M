Lua API Reference

Functions exposed by the current L2M build. All methods are client-side unless noted.

Experimental
i
API stability

These methods describe the implementation currently in the repository. Signatures and behavior may change between releases.

Chat messages

Display a message in the local Minecraft chat interface. The aliases below share the same implementation and do not send a message to a multiplayer server.

l2m.chat(message)Client
l2m.clientChat(message)Alias
l2m.systemChat(message)Alias
Lua
l2m.chat("Hello from Lua!")
l2m.clientChat("Local message")
l2m.systemChat("System-style local message")
ParameterTypeDescription
messagestringMessage text. Current bridge accepts 1–256 characters and rejects blank input.

Logging

Write a message to the L2M logger with a Lua prefix.

l2m.log(value)Client
Lua
l2m.log("Script started")
l2m.log("Player level: " .. tostring(level))
ParameterTypeDescription
valueanyConverted to text before being written to the log.

HUD drawing

Queue simple shapes and text for the client GUI render event. Coordinates use GUI screen space.

l2m.drawText(x, y, text, color?)Client
l2m.drawRect(x, y, width, height, color)Client
l2m.clearDraw()Client
Lua
l2m.drawText(12, 12, "L2M is active")
l2m.drawText(12, 30, "Custom color", 0xFF50E0D2)
l2m.drawRect(10, 52, 140, 3, 0xFF50E0D2)
l2m.clearDraw()
ParameterTypeDescription
x, yintegerTop-left screen coordinates.
textstringText to draw; maximum 512 characters.
width, heightintegerRectangle dimensions, each in the 0–4096 range.
colorintegerARGB color. drawText defaults to opaque white.

Drawing calls are queued until cleared or the bridge is reset by another script execution.

Generated content definitions

Save JSON definitions under config/l2m/generated. Definitions are read during mod initialization; restart Minecraft after adding or changing one.

l2m.registerBlock(id, properties)Startup
Lua · Block definition
l2m.registerBlock("ruby_ore", {
  displayName = "Ruby Ore",
  hardness = 3.0,
  requiresTool = true
})
l2m.registerItem(id, properties)Startup
Lua · Item definition
l2m.registerItem("ruby", {
  displayName = "Ruby",
  stackSize = 16
})
PropertyApplies toBehavior
idBoth1–48 lowercase letters, numbers or underscores.
displayNameBothOptional display name; defaults to the ID.
hardnessBlockOptional number; defaults to 1.5.
requiresToolBlockOptional boolean; defaults to false.
stackSizeItemOptional integer from 1–99; defaults to 64.

These methods create basic registered content from saved definitions. They do not currently provide custom models, textures, recipes or live registry changes.

Client commands

/l2m run <file>

Execute config/l2m/scripts/<file>.lua. Omit the extension.

/l2m package run <package> <script>

Execute a Lua file inside an installed package's scripts directory.

/l2m packages

List package directories under config/l2m/packages.

Package format

Packages are directories containing a package.json manifest and Lua scripts. L2M scans package directories when joining a world and runs a valid configured entrypoint.

package.json
{
  "id": "my_package",
  "entrypoint": "scripts/main.lua"
}

The manifest ID must match the package folder. The entrypoint is a relative Lua path inside that package.
