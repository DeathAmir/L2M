Project structure

A practical map of the folders used by L2M scripts and generated content.

Runtime configuration

Minecraft instance / config / l2m
config/l2m/
├── scripts/
├── packages/
└── generated/
    ├── blocks/
    └── items/

scripts/

Standalone Lua files live here. Run one with /l2m run <file>.

packages/

Each package has its own folder, a package.json manifest and a Lua entrypoint.

generated/

Block and item registration writes JSON definitions into separate blocks/ and items/ folders. These definitions are loaded when Minecraft starts.

Execution model

L2M uses LuaJ 3.0.1 with Lua 5.1-compatible behavior. Client scripts can write chat messages and logs and queue HUD drawing operations. Package entrypoints are also evaluated at startup for content registration.
