Commands

Run these commands in Minecraft chat. L2M executes Lua scripts on your client.

Run a script

/l2m run <file>Client

Runs config/l2m/scripts/<file>.lua. Enter the filename without the .lua extension.

Minecraft chat
/l2m run hello

Run a package script

/l2m package run <package> <script>Client

Executes a Lua file from the selected package's scripts folder. Provide the package ID and script filename without .lua.

Package manager

/l2m packages Alias

Lists installed package folders. The package manager also provides validation, metadata inspection and lifecycle controls.

Package commands
/l2m package list
/l2m package info hello-world
/l2m package validate hello-world
/l2m package disable hello-world
/l2m package enable hello-world
/l2m package remove hello-world

validate checks the manifest ID, entrypoint location and declared dependencies. disable prevents automatic startup loading; enable restores it. remove permanently deletes the selected installed package directory after confirming its manifest exists.

Developer console

/l2m console

Opens the in-game runtime console. It shows recent script execution messages, package operations, event callback errors and the current event-listener count. Use Clear log to reset the visible history.

Client events

Register callbacks from Lua with l2m.on(eventName, callback). Currently supported events are client_tick, player_join and player_leave. Join and leave callbacks receive the local player's name; tick callbacks run once per client tick while in a world.

events.lua
l2m.on("player_join", function(playerName)
    l2m.log(playerName .. " joined the world")
end)

l2m.on("client_tick", function()
    -- Runs every client tick. Keep callbacks lightweight.
end)
Tip

If a command cannot find a script, check its folder and filename, and make sure the file ends in .lua.
