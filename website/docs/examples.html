01 · CHAT & LOG

Messages and logs

Local chat messagechat aliases＋
l2m.chat("Hello, Minecraft!")
l2m.clientChat("This is local chat.")
l2m.systemChat("L2M says hi!")

These aliases add text to the local chat UI; they do not send a message to the server.

Write to the loglog＋
l2m.log("Script started")
l2m.log("Player script loaded")
02 · GUI DRAWING

Draw simple HUD elements

l2m.drawText(12, 12, "L2M is running", 0xFFFFFFFF)
l2m.drawRect(10, 34, 150, 4, 0xFF50E0D2)

-- Remove all queued drawing calls
l2m.clearDraw()

Text and rectangles are drawn by the client GUI render event. Coordinates are screen GUI coordinates.

03 · GENERATED CONTENT

Define items and blocks

Create a block definitionregisterBlock＋
l2m.registerBlock("copper_crystal", {
  displayName = "Copper Crystal",
  hardness = 2.5,
  requiresTool = true
})
Create an item definitionregisterItem＋
l2m.registerItem("copper_fragment", {
  displayName = "Copper Fragment",
  stackSize = 32
})

Definitions are saved under config/l2m/generated and loaded during Minecraft startup. Restart the game after creating them. These methods do not create custom textures, models or recipes.

04 · PACKAGES

Run a package script

/l2m package run my_package main
/l2m packages

To auto-run a package when joining a world, add a package.json manifest:

{
  "id": "my_package",
  "entrypoint": "scripts/main.lua"
}
API LIMITS

Know what's implemented.

Timers, event hooks, server-side scripts, world editing and dynamic registry updates are not exposed by the current public API. See the reference for exact signatures and constraints.
