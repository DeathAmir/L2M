Lua examples

Practical examples built only from functions available in the current L2M release.

Chat and logging

messages.lua
l2m.chat("Hello, Minecraft!")
l2m.log("messages.lua loaded")

HUD overlay

Draw a label and a simple accent bar on the client screen.

hud.lua
l2m.drawText(12, 12, "L2M is running", 0xFFFFFFFF)
l2m.drawRect(10, 34, 150, 4, 0xFF50E0D2)

Generated block

block.lua
l2m.registerBlock("copper_crystal", {
  displayName = "Copper Crystal",
  hardness = 2.5,
  requiresTool = true
})
!
Restart required

Generated block and item definitions are loaded during Minecraft startup. Restart after creating or changing them.

Generated item

item.lua
l2m.registerItem("copper_fragment", {
  displayName = "Copper Fragment",
  stackSize = 32
})

/l2m package run my_package main
