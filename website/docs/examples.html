LUA RECIPES

Small scripts.
Real game chat.

Copy a sample into config/l2m/scripts and run it with /l2m run filename.

Hello message

l2m.chat("Hello, Minecraft!")

Save as hello.lua, then run /l2m run hello.

Multiple messages

l2m.chat("L2M is loaded!")
l2m.chat("This message was sent by Lua.")

Each call sends one normal client chat message. Server chat rules still apply.

API availability

At this preview stage, l2m.chat(message) is the only public Lua function. Timers, event hooks, server-side scripts, and world-editing APIs are not available yet.
