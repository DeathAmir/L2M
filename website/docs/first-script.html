Your first Lua script

Create a Lua file, call the L2M API, and execute it in your Minecraft world.

Create the file

Inside your Minecraft instance, create config/l2m/scripts/hello.lua.

hello.lua
l2m.chat("Hello from Lua2Minecraft!")
l2m.log("hello.lua executed")

Run it in-game

Start a world, open chat, and run:

Minecraft chat
/l2m run hello
