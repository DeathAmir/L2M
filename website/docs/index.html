01 · INSTALLATION

Install the mod

RequirementsMinecraft 1.21.1 · NeoForge · Java 21＋
  1. Install Minecraft 1.21.1 with NeoForge.
  2. Download the latest L2M JAR from GitHub Releases.
  3. Place L2M-x.y.z.jar in your Minecraft mods folder.
  4. Start the game.
Where scripts goConfig directory＋

Standalone scripts are stored in config/l2m/scripts. Package folders are stored in config/l2m/packages.

The folders are created when the corresponding command or package scan runs.

02 · FIRST SCRIPT

Your first Lua file

Create config/l2m/scripts/hello.lua:

l2m.chat("Hello from Lua and L2M!")
l2m.log("hello.lua executed")

Join a world and run:

/l2m run hello
03 · COMMANDS

Explore commands

Command reference →
/l2m run <file>Execute a script from scripts/＋
Example: /l2m run hello
/l2m package run <package> <script>Execute a package script＋
Example: /l2m package run my_package main
/l2m packagesList installed packages＋
Lists package directories under config/l2m/packages.
SAFETY & STATUS

Run scripts you trust.

Scripts execute locally and have access to LuaJ's standard globals. The API is experimental. The current public API includes chat, logging, basic GUI drawing, generated item/block definitions and package execution.
