L2M embeds LuaJ with Lua 5.1-compatible scripting and exposes a small client API. This first preview focuses on running scripts and sending chat messages.

Download L2M
01 · INSTALLATION

Install the mod

  1. Install Minecraft 1.21.1 with NeoForge.
  2. Download the L2M JAR from GitHub Releases.
  3. Put L2M-x.y.z.jar into your Minecraft mods folder.
  4. Start the game and join a world.
02 · YOUR FIRST SCRIPT

Create hello.lua

Create config/l2m/scripts/hello.lua:

l2m.chat("Hello from Lua and L2M!")

In-game, run /l2m run hello.

Scripts execute on the client. Only run Lua files you trust. The scripting API is experimental and currently exposes chat only.

03 · CLIENT COMMANDS

Commands

  • /l2m run <file> — executes <file>.lua.
  • /l2m chat <message> — sends a message directly from the client.
