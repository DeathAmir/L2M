Install L2M

Set up the required Minecraft environment and install the mod JAR.

Requirements

ComponentRequired version
Minecraft1.21.1
Mod loaderNeoForge 21.1.252
Java21

Install steps

  1. Install Minecraft 1.21.1 and the matching NeoForge profile.
  2. Download the latest L2M JAR from GitHub Releases.
  3. Place the JAR in the mods folder of the game directory.
  4. Launch Minecraft using the NeoForge profile.

Configuration directory

L2M stores scripts and packages in the Minecraft configuration directory:

Directory layout
config/
└── l2m/
    ├── scripts/
    ├── packages/
    └── generated/
