Quick start

Create a file at config/l2m/scripts/hello.lua:

hello.lua
l2m.chat("Hello from Lua2Minecraft!")
l2m.log("My first L2M script is running")

Open a world and run the script from chat:

Minecraft chat
/l2m run hello
