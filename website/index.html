01

Install

Install NeoForge for Minecraft 1.21.1 and place the L2M JAR in your mods folder.

02

Create a script

Create config/l2m/scripts/hello.lua and add your Lua code.

03

Run in-game

Join a world and execute /l2m run hello in chat.

QUICK REFERENCE

Commands

/l2m run <file>Run a script from config/l2m/scripts＋

Runs <file>.lua from the scripts directory.

/l2m run hello
/l2m package run <package> <script>Run a script inside an installed package＋

Runs config/l2m/packages/<package>/scripts/<script>.lua.

/l2m packagesList installed package folders＋

Lists directories found in config/l2m/packages.

EARLY DEVELOPMENT

Built to grow.

The public API is experimental and may change. Scripts run locally with broad LuaJ standard libraries; only run scripts you trust. Generated blocks and items are registered when Minecraft starts, so restart after creating a definition.
