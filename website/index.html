GETTING STARTED

Run your first script

  1. Install the L2M JAR and NeoForge for Minecraft 1.21.1.
  2. Launch the game once. L2M creates config/l2m/scripts when you add your first script folder.
  3. Create hello.lua in that folder.
  4. Enter a world and run /l2m run hello.
l2m.chat("Hello from Lua 5.1!")

The API is an early preview. At this stage, scripts can send chat messages from the client. More game APIs will be added gradually.

LUA API · FIRST FUNCTION

Chat

l2m.chat(message) sends a message using the connected Minecraft client. The message is subject to the server's normal chat rules and limits.

l2m.chat("Hello, server!")
l2m.chat("This message came from a Lua script.")

See the examples folder for a ready-to-use script.

PROJECT STATUS

Early development

L2M currently embeds LuaJ, a Java implementation of Lua 5.1. Its public scripting API is experimental and may change between versions.
