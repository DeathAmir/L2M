Generated blocks and items

L2M writes block and item definitions from Lua. These definitions are loaded during Minecraft startup, not immediately in an active world.

Register a block

block.lua
local saved = l2m.registerBlock("ruby_ore", {
    displayName = "Ruby Ore",
    hardness = 3.0,
    requiresTool = true
})
l2m.log("Saved: " .. tostring(saved))

The current loader stores displayName as metadata; it does not yet apply it as the visible in-game name. Hardness defaults to 1.5 and requiresTool defaults to false.

Register an item

item.lua
l2m.registerItem("ruby", {
    displayName = "Ruby",
    stackSize = 16
})

Stack size defaults to 64. The registry loader accepts values from 1 to 99. Check the value because the manual-script writer does not validate this range before saving.

Restart Minecraft after changing generated definitions. The active registry reads these files at startup.

Read registerBlock and registerItem for full signatures.
