Frequently asked questions

Quick answers about the currently documented L2M behavior.

Which versions are supported?

The documented target is Minecraft 1.21.1, NeoForge 21.1.252 and Java 21.

Which Lua runtime does L2M use?

L2M uses LuaJ 3.0.1 with Lua 5.1-compatible behavior.

Do chat messages appear for everyone?

No. l2m.chat writes to your local Minecraft chat. It does not send messages to a multiplayer server.

Why did my HUD drawing disappear?

Check that the script ran successfully and that you have not called l2m.clearDraw() afterward. Drawing calls are queued for the client HUD.

Why is a generated block not available immediately?

Generated block and item definitions are loaded during Minecraft startup. Restart the game after writing definitions.

Where can I report a bug?

Use the L2M issue tracker. Include reproduction steps, Minecraft / NeoForge / Java versions and relevant logs.
