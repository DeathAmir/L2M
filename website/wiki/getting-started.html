Getting started

Set up the supported environment, install the mod and run a first script.

Requirements

ComponentTarget
Minecraft1.21.1
NeoForge21.1.252
Java21
Lua runtimeLuaJ 3.0.1, Lua 5.1-compatible

Install the mod

  1. Install Minecraft 1.21.1 and NeoForge 21.1.252.
  2. Download the L2M JAR from GitHub Releases.
  3. Place the JAR in your instance's mods directory.
  4. Launch the NeoForge profile once so L2M can create its configuration folders.

Create your first script

Create config/l2m/scripts/hello.lua:

hello.lua
l2m.chat("Hello from L2M!")
l2m.log("The script executed")

Run in Minecraft

Join a world, open chat, and enter:

Minecraft command
/l2m run hello

Continue with the API reference or the examples.
