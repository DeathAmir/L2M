Lua basics for L2M

L2M scripts use LuaJ with Lua 5.1-compatible behavior. This page covers a few language basics that are useful when writing your first scripts.

Variables and values

variables.lua
local playerName = "Steve"
local coins = 120
local isReady = true

l2m.log(playerName .. " has " .. tostring(coins) .. " coins")

Use local for variables that should stay within the current scope. Lua concatenates strings with ..; use tostring when joining numbers or booleans into text.

Functions

functions.lua
local function welcome(name)
    l2m.chat("Welcome, " .. name)
end

welcome("Alex")

Tables

tables.lua
local player = {
    name = "Alex",
    level = 7
}

l2m.log(player.name)

Calling L2M functions

The L2M API is exposed through the global l2m table. Use the API reference for exact signatures, constraints and return values. Do not assume that a standard Lua library or Minecraft Java class is exposed unless the project documents it.
