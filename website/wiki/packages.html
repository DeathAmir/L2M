Script packages

Packages group related Lua files and provide an entrypoint L2M can discover and run.

Folder layout

config/l2m/packages/
my_package/
├── package.json
└── scripts/
    └── main.lua

Manifest

package.json
{
  "id": "my_package",
  "entrypoint": "scripts/main.lua"
}

The manifest ID must match the folder name. The entrypoint must point to a Lua file inside the package folder.

Loading lifecycle

At startup, L2M evaluates the entrypoint in a registration pass. Only l2m.registerBlock and l2m.registerItem perform registration during that pass. When you join a world, the entrypoint runs again as a normal client script.

Commands

Minecraft chat
/l2m packages
/l2m package run my_package main

See the package reference for details.
